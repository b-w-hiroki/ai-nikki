# AI Nikki — スマート日記アシスタント

> 「今日をめくる → 書く → 過去の自分と比べる」

日めくりカレンダーをめくる行為がアプリの起点。1日1ページの気軽さで書き続けると、いつの間にか自分だけの記録集が完成する。

## 🚀 起動方法

```bash
npx --yes serve -l 3000
```

ブラウザで `http://localhost:3000/app.html` を開く。

## ✨ 機能

| 機能 | 説明 |
|------|------|
| 日めくりカレンダー | フリップアニメーション付き。今日の日付を大きく表示 |
| 気分スタンプ | 5段階（最高/いい感じ/ふつう/ちょっと…/つらい）、選択アニメーション付き |
| 日記テキスト | 罫線付きノート風テキストエリア（Klee One フォント） |
| 写真添付 | カメラ撮影/ギャラリー対応。Canvas で max 800px に自動圧縮 |
| 積み上げトラッカー | 読書・運動・勉強の3カテゴリ。トグル表示 |
| 保存機能 | localStorage に永続保存。リップル + トースト演出 |
| ストリーク | 連続記録日数を炎アニメーションで表示 |
| EXP & レベル | 日記保存・写真・積み上げで EXP 獲得。レベルアップ演出 |
| バッジ | 初投稿・7日連続などの実績バッジをモーダルで解放 |
| 月間カレンダー | 気分カラーのドットで記録済み日を可視化 |
| タイムトラベルカード | 1ヶ月前/1年前の日記を自動表示 |
| PWA 対応 | オフライン動作、ホーム画面追加 |

## 🛠 技術スタック

- HTML5 + CSS3 + JavaScript (ES Modules)
- ブラウザ内蔵 Prompt API（対応環境のみ。外部AI APIは未接続）
- localStorage（既定の保存先）＋任意の Supabase 手動バックアップ
- Service Worker（PWA/オフライン）
- Google Fonts（Zen Maru Gothic / Noto Sans JP / Klee One）

### 追加機能（以下は外部AI API不要）
データ・体験まわり
- **データのエクスポート / インポート**: 全データを JSON でバックアップ・復元（設定 ⚙ から）
- **テーマ切替**: ペーパー / ミッドナイト / レトロ / フォレスト / さくらの 5 テーマ
- **感情コレクション図鑑**: 気分 5 種の解放状況 + レアコンボ（カムバック等）を自動検出
- **気分バランスバー**: 気分ごとの記録回数を可視化
- **Year in Review**: 1 年の記録を Spotify Wrapped 風 5 スライドでふりかえり（画像保存対応）

続けやすさ・使いやすさ
- **初回オンボーディング**: はじめて開いたとき使い方を 4 ステップで案内
- **今日のお題**: 日替わりの問いかけ。タップで本文に挿入
- **日記の全文検索**: カレンダー画面からキーワードで過去日記を検索（ヒット箇所をハイライト）
- **今週のふりかえり**: 直近 7 日の気分と記録日数をマイページに表示
- **カスタム積み上げカテゴリ**: 読書・運動・勉強のほかに自由に追加（設定 ⚙ から）
- **書き忘れリマインド**: 今日まだ記録していないときホームに通知

## データ保存先と通信の境界

| 操作 | データの扱い |
|---|---|
| 通常の日記保存 | このサイト・端末・ブラウザの `localStorage` に保存。クラウドへの自動同期はありません |
| JSONエクスポート | 日記・気分・写真・積み上げ・設定・統計・目標をファイルに保存 |
| クラウドに保存（任意） | ログイン後にボタンを押すと、同じバックアップ内容を設定先の Supabase `backups` に送信。アカウントごとに前回のバックアップを置き換えます |
| クラウドから復元 | クラウドのバックアップを端末へインポート。対象データが上書きされるため、先にJSONをエクスポートしてください |
| 内蔵AI | 下記のテキストをブラウザ内蔵モデルに渡します。アプリから外部AIサービスへの送信は実装していません |

端末内保存は暗号化された金庫ではありません。同じブラウザを使える人や同一サイト上のスクリプトからのアクセス、端末紛失に注意してください。サイトデータ削除・プライベートモード終了・容量制限などで失われる可能性があります。端末変更時はエクスポート → インポートし、内容を確認してください。

**端末内保存＝外部通信ゼロではありません。** 初回表示等で Google Fonts、cdnjs（画像書き出し用 html2canvas）を読み込みます。クラウド設定後は esm.sh から Supabase SDK を読み込み、設定したプロジェクトと認証・セッション確認の通信をします。これらの外部スクリプトはページ上で実行される依存先です。ブラウザ内蔵AIのモデル準備にもダウンロードが必要な場合があります。

### 任意のSupabaseバックアップ

設定画面で自分が管理するプロジェクトの URL と **anon public key** を入力します。`service_role` や秘密鍵は入力しないでください。メールログインでは入力したメールアドレスが設定先へ送信され、GoogleログインではOAuth認証ページへ移動します。利用枠や費用はSupabase側の契約によります。

プロジェクトのSQLエディタで、次のテーブルと本人限定のRLSポリシーを設定してください。既存テーブルがある場合は重複実行せず定義を確認してください。認証のリダイレクトURLにアプリのURLを登録し、Googleログインを使う場合はプロバイダー設定も必要です。

```sql
create table backups (
  user_id uuid primary key references auth.users on delete cascade,
  data jsonb,
  updated_at timestamptz default now()
);
alter table backups enable row level security;
create policy "own" on backups for all
  using (auth.uid() = user_id) with check (auth.uid() = user_id);
```

RLSは利用者が設定する前提で、アプリは適用状態を検証しません。他ユーザーのデータを読めない・書けないことを確認してから使ってください。クラウド接続設定と認証セッションはJSONバックアップ対象外です。ただし日記の設定データは含まれます。旧設定の `apiKey` 等が残っている場合、JSONファイル・クラウドの両方のバックアップに含まれます。秘密情報が残っていないか確認してから利用してください。ログアウトや接続設定の変更は、保存済みクラウドバックアップの削除ではありません。

### 内蔵AIの対応条件

`window.LanguageModel` または旧 `window.ai.languageModel` を検出し、利用可能状況を確認します。ブラウザ・OS・端末性能・空き容量・モデル提供状況で利用可否が異なり、最新Chromeやスマートフォンでも利用を保証しません。

- **保存後のひとこと**: 4文字以上の日記保存後、対応環境では本文と気分を内蔵AIに渡します。モデルの準備・ダウンロードが発生する場合があります。
- **チャット**: 入力したメッセージと、セッション作成時の直近3件の日付・気分・本文先頭80文字を文脈に使います。写真は渡しません。チャットの履歴はページ上の一時データで、JSONバックアップには含まれません。
- 非対応ならチャットに案内を表示し、日記保存・写真・集計はそのまま利用できます。生成に失敗した場合も通常の日記保存は維持します。
- 専用のAI感情分析・AI週次レポート・Claude/Gemini等の外部API連携は未実装です。AIの応答は誤りを含むことがあり、医療・心理相談の代わりにはなりません。

## 写真とバックアップの確認

写真は長辺800px・JPEG品質0.7に圧縮します。読込・画像形式・圧縮で失敗したときはメッセージを表示し、元の添付写真を残します。読込中に別の写真を選ぶ、削除する、別の日記に移る場合は、遅れて完了した古い選択で上書きしません。容量制限はブラウザごとに異なり、圧縮しても保存できることを保証するものではありません。

端末変更やブラウザのデータ削除前は、設定からJSONをエクスポートしてください。別端末でインポート後、日付・本文・写真・設定を確認してから元のデータを削除してください。バックアップには日記や写真が含まれるため、他人に共有せず安全な場所に保存してください。

回帰テスト: `node --test tests/*.test.mjs`。写真の失敗と選択競合はブラウザAPIを模したテストで検証します。実機の画像形式・カメラ・ストレージ容量や見た目は別途確認が必要です。
